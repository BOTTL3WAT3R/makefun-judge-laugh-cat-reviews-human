A one-line, one-star review of a human, written in the voice of the house cat who employs him: the bowl refilled only once empty, the bedroom door shut nightly, the warm laptop occupied all day — and the rent, paid in mice, never once thanked. The program writes the review to /output/entry.txt for the make.fun judge to compare head to head.

## Run it

```sh
python3 main.py
```
